## 🎯 Overview

This repository is **not a coding project** — it is a structured collection of everything I studied, submitted, and prepared throughout the semester for **CSE325: Instrumentation and Control**, taught by **Mehedi Hasan Sir**. This course focuses on the sensors, measurement systems, and control mechanisms that bridge computing with the physical world — so this repository holds assignments, midterm/final exam materials, presentation slides, quiz preparation notes, and reference books, all organized in one place for easy review and future reference.

---

## 📚 Course Overview

**CSE325 — Instrumentation and Control** covers the fundamentals of measurement systems, sensors, transducers, and control system design — the engineering foundation behind how electronic and computer-based systems sense, interpret, and control physical processes.

Key areas typically covered in this course include:

- Fundamentals of instrumentation and measurement
- Sensors and transducers
- Signal conditioning and data acquisition
- Control system basics (open-loop vs. closed-loop systems)
- Feedback control systems
- Industrial instrumentation concepts
- Applications of instrumentation and control in real-world systems

## 🧠 Learning Focus

This course connected core electrical and computing concepts to real-world **sensing and control systems**. Key learning areas included:

- **Measurement Systems** — principles behind accurately measuring physical quantities
- **Sensors & Transducers** — how physical signals (temperature, pressure, light, motion, etc.) are converted into usable electrical signals
- **Signal Conditioning** — processing raw sensor data into a usable form
- **Control Systems** — designing systems that automatically regulate a process based on feedback
- **Industrial Applications** — how instrumentation and control principles are applied in real industrial and automation settings
